OHT · Motion programming

Applied parameters directly control the animation

Units: maxSpeed = m/s, accel & decel = m/s², pickupDwell & dropDwell = seconds. Track distance is scaled at 100 px per simulated metre.

Controller method referenceUsed by this simulator
function stepOHT(vehicle, dt) {
  const m = vehicle.current;
  if (!m) return;
  if (m.dwell > 0) { m.dwell -= dt; if (m.dwell > 0) return; }
  if (m.phase === 'pickup') m.phase = 'move';
  if (m.phase === 'drop') { completeVehicleTask(vehicle); return; }

  const remaining = Math.max(0, m.distanceM - m.sM);
  const p = vehicle.program;
  const stopDistance = (m.vMps * m.vMps) / (2 * p.decel);
  const accelerating = remaining > stopDistance + 0.002;
  const a = accelerating
    ? (m.vMps < p.maxSpeed ? p.accel : 0)
    : -p.decel;
  const nextV = clamp(m.vMps + a * dt, 0, p.maxSpeed);
  m.sM += (m.vMps + nextV) * 0.5 * dt;
  m.vMps = nextV;

  if (m.sM >= m.distanceM || (remaining < 0.005 && m.vMps < 0.03)) {
    m.sM = m.distanceM; m.vMps = 0; m.phase = 'drop';
    m.dwell = p.dropDwell; vehicle.x = m.to.x; vehicle.y = m.to.y;
    return;
  }
  const ratio = clamp(m.sM / m.distanceM, 0, 1);
  vehicle.x = m.from.x + (m.to.x - m.from.x) * ratio;
  vehicle.y = m.from.y + (m.to.y - m.from.y) * ratio;
}
The stopping-distance check starts deceleration early enough to approach the destination at low speed. This is a teaching-level point-to-point profile, not a certified safety controller or full jerk-limited drive.
